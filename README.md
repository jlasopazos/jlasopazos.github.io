# Jesús Laso-Pazos: personal website

Source of https://jlasopazos.github.io, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (MIT license) and published with GitHub Pages.

## Where things are

| What | File |
|---|---|
| Name, email, sidebar links (LinkedIn, Google Scholar, ORCID, ...) | `_config.yml` |
| Home page text | `_pages/about.md` |
| Research page | `_pages/research.md` |
| Teaching page | `_pages/teaching.md` |
| Menu at the top | `_data/navigation.yml` |
| CV and paper PDFs | `files/` |
| Profile photo | `images/` (then set `avatar` in `_config.yml`) |

## Common updates

- **New CV or paper version:** upload the PDF to `files/` with the same file name as the old one (`Jesus_Laso_Pazos_CV.pdf`, `Jesus_Laso_Pazos_JMP.pdf`). Links keep working, so no page needs editing.
- **New paper:** copy an existing entry in `_pages/research.md` and edit it.
- **Text changes:** open the file on GitHub, click the pencil icon, edit, then "Commit changes".

Each commit rebuilds the site automatically within a few minutes. Progress and any errors appear in the **Actions** tab.
